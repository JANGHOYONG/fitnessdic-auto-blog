## 📋 아티클 페이지 전체 레이아웃

순서대로 배치:

```
[Breadcrumb]
[카테고리 뱃지] [읽는 시간] [업데이트일]
[제목 H1]
[부제목/요약 2~3줄]
[대표 이미지 16:9]
[Byline 박스]  ← 저자 아바타 + 이름 + 자격 + 감수자
[면책 배너]    ← YMYL 카테고리일 때만
[Table of Contents]  ← sticky 사이드 or 상단 접힘
[본문]
  ↳ h2, h3 구조
  ↳ 핵심 인용구 <blockquote>
  ↳ 중간 인포그래픽 1장
  ↳ 비교표
  ↳ 체크리스트
  ↳ 글 중간 쿠팡 배너 1개
[FAQ]  ← 4~6개
[출처 리스트]  ← 각주 포맷
[저자 소개 카드]  ← 저자 페이지 링크
[관련글 3개]
[카테고리로 돌아가기 링크]
[뉴스레터 CTA]
```

### 3) `src/components/TableOfContents.tsx`

- 본문 MDX/HTML에서 h2/h3 자동 스캔
- 데스크탑: sticky right column
- 모바일: 상단 접힘(Collapse) UI
- 스크롤 스파이로 현재 섹션 하이라이트

```tsx
"use client";
import { useEffect, useState } from "react";

export default function TableOfContents({ headings }) {
  const [active, setActive] = useState("");
  useEffect(() => {
    const observer = new IntersectionObserver(
      (entries) => entries.forEach(e => e.isIntersecting && setActive(e.target.id)),
      { rootMargin: "-80px 0px -70% 0px" }
    );
    headings.forEach(h => { const el = document.getElementById(h.id); el && observer.observe(el); });
    return () => observer.disconnect();
  }, [headings]);
  // ...렌더
}
```

### 4) `src/components/SourceList.tsx`

본문 말미 "출처" 섹션을 각주 스타일로 렌더한다.

```tsx
export default function SourceList({ sources }) {
  if (!sources?.length) return null;
  return (
    <section className="mt-12 pt-6 border-t border-border">
      <h3 className="text-lg font-bold mb-3">📚 참고 문헌</h3>
      <ol className="text-sm text-text/80 space-y-2 list-decimal pl-5">
        {sources.map((s, i) => (
          <li key={i}>
            {s.url ? (
              <a href={s.url} target="_blank" rel="nofollow noopener" className="hover:text-primary underline">
                {s.title}
              </a>
            ) : s.title}
            {s.publisher && <span className="text-text/60"> · {s.publisher}</span>}
            {s.accessedAt && <span className="text-text/60"> (조회 {new Date(s.accessedAt).toLocaleDateString("ko-KR")})</span>}
          </li>
        ))}
      </ol>
    </section>
  );
}
```

### 5) `src/components/RelatedPosts.tsx`

같은 카테고리 + 같은 태그가 교집합인 글을 최대 3개 추천. 내부 링크는 SEO에 직접 영향을 준다.

```tsx
export default async function RelatedPosts({ currentSlug, categoryId, tags }) {
  const related = await prisma.post.findMany({
    where: {
      status: "PUBLISHED",
      slug: { not: currentSlug },
      OR: [
        { categoryId },
        { tags: { hasSome: tags } },
      ],
    },
    take: 3,
    orderBy: { publishedAt: "desc" },
  });
  // 렌더: 카드 3개 그리드
}
```

- [ ] 저자 바이라인이 제목 바로 아래 노출

## 🧠 체크포인트

- 글 중간 광고는 본문 길이에 따라 삽입 위치를 자동 조정 (2,500자 이상 시 1개, 4,000자 이상 시 2개).
- 대표 이미지는 `next/image`의 `priority={true}` 설정하여 LCP 최적화.
- `<time dateTime=...>` 태그를 사용하여 기계 가독성 확보.
