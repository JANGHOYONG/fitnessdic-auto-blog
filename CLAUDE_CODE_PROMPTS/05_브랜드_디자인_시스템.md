# 05 · 브랜드·디자인 시스템 전면 리뉴얼

## 🎯 목표

다이어트·건강·피부미용을 모두 아우르면서도 20~40대 남녀가 '깔끔하고 고급스럽다'고 느끼는 **통합 브랜드 아이덴티티**를 구축한다. 기존 '에너지 오렌지'를 유지하되, 건강·피부미용의 '클린·내추럴' 코드를 섞어 **Coral × Sage** 듀얼 톤으로 확장한다.

디자인은 '정보 위계 → 가독성 → 신뢰감' 순서로 설계한다. 화려한 그래디언트·애니메이션은 배제.

| 용도 | Size / Line | Weight |

## 📋 구체 지시사항

### 1) `tailwind.config.ts`

```typescript
import type { Config } from "tailwindcss";

export default {
  content: ["./src/**/*.{ts,tsx}"],
  theme: {
    extend: {
      colors: {
        coral: { 50:"#FFF5EE",100:"#FFE4D1",200:"#FFC8A0",300:"#FFA867",400:"#FF8437",500:"#E8631A",600:"#C4501A",700:"#9A3D14",800:"#6F2B0E",900:"#451A08" },
        sage:  { 50:"#F2F8F3",100:"#DFEEE2",200:"#BCDCC2",300:"#97C8A1",400:"#74B583",500:"#5AA069",600:"#478253",700:"#36623F",800:"#24422A",900:"#122216" },
        rose:  { 50:"#FDF7F4",100:"#F8E6DE",200:"#F0CDBD",300:"#E5AC93",400:"#D38C6E",500:"#BA6D4E" },
        bg:    "#FFFCF8",
        surface:"#FFFFFF",
        text:  { DEFAULT:"#1E1511", mute:"#6B625C" },
        border:"#EFE6DC",
      },
      fontFamily: {
        sans: ["Pretendard Variable","Pretendard","Malgun Gothic","sans-serif"],
        serif:["Noto Serif KR","serif"],
      },
      borderRadius: { sm:"6px", md:"10px", lg:"16px", xl:"24px", full:"9999px" },
      boxShadow: {
        card:"0 1px 3px rgba(30,21,17,0.06), 0 4px 12px rgba(30,21,17,0.04)",
        soft:"0 2px 6px rgba(30,21,17,0.05)",
      },
```

`@tailwindcss/typography`로 본문 prose 스타일 자동. `prose-headings:text-text prose-a:text-coral-600` 등 커스텀.

### 2) `src/app/globals.css`

```css
@tailwind base;
@tailwind components;
@tailwind utilities;

@font-face { font-family:"Pretendard Variable"; src:url("/fonts/Pretendard/PretendardVariable.woff2") format("woff2-variations"); font-weight:45 920; font-display:swap; }

:root {
  --bg:#FFFCF8; --surface:#FFFFFF; --text:#1E1511; --text-mute:#6B625C;
  --coral:#E8631A; --coral-dark:#C4501A; --sage:#5AA069; --rose:#BA6D4E;
  --border:#EFE6DC;
}
html { color-scheme:light; scroll-behavior:smooth; }
body { background:var(--bg); color:var(--text); font-family:"Pretendard Variable",sans-serif; line-height:1.75; -webkit-font-smoothing:antialiased; }
h1,h2,h3,h4 { color:var(--text); font-weight:700; letter-spacing:-0.02em; }

/* 카테고리별 액센트 (data-accent 속성) */
[data-accent="coral"] { --accent:var(--coral); }
[data-accent="sage"]  { --accent:var(--sage); }
[data-accent="rose"]  { --accent:var(--rose); }

/* 공통 유틸 */
.container-content { @apply mx-auto max-w-content px-4; }
.container-wide    { @apply mx-auto max-w-wide px-4; }
.card              { @apply bg-surface rounded-lg shadow-card border border-border; }
.btn-primary       { @apply bg-coral-500 text-white hover:bg-coral-600 px-5 py-3 rounded-md font-semibold; }
.btn-ghost         { @apply text-text hover:bg-coral-50 px-4 py-2 rounded-md; }
.badge             { @apply inline-flex items-center gap-1 px-2 py-0.5 rounded-full text-xs font-medium; }
.badge-coral       { @apply badge bg-coral-50 text-coral-700; }
.badge-sage        { @apply badge bg-sage-50 text-sage-700; }
.badge-rose        { @apply badge bg-rose-50 text-rose-500; }
```

### 3) `src/components/Header.tsx`

구조:
```
[로고 💪💄🥗 다이어트·건강·피부미용 백과]  [검색 🔍] [메뉴 ☰]
────────────────────────────────────────────────────
[다이어트] [운동] [식단·영양] [건강] [피부미용] [홈트] [뉴스레터]
```

- sticky top-0, backdrop-blur + 반투명 배경
- 스크롤 시 shadow 적용 (IntersectionObserver 1px sentinel)
- 모바일: 햄버거 → Sheet 드로어 (왼쪽 슬라이드)
- 검색 아이콘 클릭 시 전체화면 Modal에서 `/search`로 이동
- 다크모드는 "준비 중" 상태로 prefers-color-scheme만 대응

### 5) `src/components/ArticleCard.tsx` 리뉴얼

- 16:9 썸네일 (Next/Image priority 하단 lazy)
- 카테고리 뱃지 (카테고리별 컬러 자동)
- 제목 2줄 ellipsis, 본문 2줄 ellipsis
- 하단 줄: 저자 아바타·이름 · 읽는 시간 · 업데이트일
- 호버 시 subtle shadow + translate-y-0.5
- 반응형: 모바일 1열, 태블릿 2열, 데스크탑 3열

### 7) `src/app/icon.tsx` (파비콘)

```tsx
import { ImageResponse } from "next/og";
export const size = { width: 64, height: 64 };
export const contentType = "image/png";
export default function Icon() {
  return new ImageResponse(
    (<div style={{
      fontSize: 40, background: "linear-gradient(135deg,#FF8437,#E8631A)",
      width:"100%", height:"100%", display:"flex", alignItems:"center", justifyContent:"center",
      color:"white", borderRadius: 14
    }}>💪</div>), size
  );
}
```

OG 기본 이미지 `/og-default.png`도 동일한 톤으로 제작 (1200×630).

## 🧠 체크포인트

- **카테고리별 '액센트 컬러' 규칙**:
  - 다이어트/운동/홈트/동기 → **Coral** (coral-500)
  - 건강/영양/식단/보충제 → **Sage** (sage-500)
  - 피부미용/스킨케어/이너뷰티 → **Rose** (rose-500)
- 이 규칙은 ArticleCard의 badge, 카테고리 페이지 헤더, 아티클 페이지 `data-accent` 속성으로 전달.
