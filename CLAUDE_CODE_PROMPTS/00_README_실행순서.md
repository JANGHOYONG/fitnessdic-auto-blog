## 📐 설계 원칙 (전 프롬프트 공통)

1. **파괴적 변경은 피하고 새 파일 추가를 우선한다** — 기존 파일 수정이 필요하면 Edit 도구로 최소 diff만.
2. **모든 신규 파일은 TypeScript + App Router 컨벤션을 따른다** — `src/app/` 하위에 추가.
3. **Tailwind 클래스는 기존 브랜드 토큰을 사용한다** — 하드코딩 금지.
4. **DB 스키마 변경 시 `prisma migrate dev`를 먼저 실행**하고 데이터 유실 여부를 검증한다.
5. **변경 후 반드시 `npm run build`로 타입·빌드 에러가 없음을 확인한다.**
6. **커밋 메시지는 `feat: …`, `fix: …`, `refactor: …` 컨벤션**을 따른다.
