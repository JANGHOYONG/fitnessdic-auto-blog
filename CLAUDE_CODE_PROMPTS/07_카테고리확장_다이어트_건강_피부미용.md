# 07 · 카테고리 확장 (10대 주제) + 주제 100선 DB 임포트

## 🎯 목표

기존 7대 운동 주제를 **다이어트·건강·피부미용을 아우르는 10대 주제**로 확장한다. 각 주제는 "검색량 × CPC × 난이도"가 고려된 우선순위를 갖는다. 이후 `02_주제100선_에디토리얼캘린더.xlsx` 데이터를 DB에 임포트하여 4개월 분의 발행 큐를 미리 채운다.

### 2) Prisma 모델 추가

```prisma
model Topic {
  id          String   @id @default(cuid())
  title       String
  categoryId  String
  keyword     String   // 핵심 검색 키워드
  searchVolume Int     // 네이버 월 검색량 추정
  cpcKrw      Int?     // 구글 CPC 추정(원)
  difficulty  Int      // 1~100 (낮을수록 쉬움)
  priority    Int      // 1~100 (높을수록 먼저)
  plannedDate DateTime?
  status      String   @default("PENDING") // PENDING | DRAFTED | PUBLISHED
  notes       String?  @db.Text
  createdAt   DateTime @default(now())
  @@index([categoryId, priority])
}
```

마이그레이션: `npx prisma migrate dev --name add_topic_table`

### 3) `scripts/import-topics.js`

```javascript
const XLSX = require("xlsx");
const path = require("path");
const { PrismaClient } = require("@prisma/client");
const prisma = new PrismaClient();

async function main() {
  const wb = XLSX.readFile(path.resolve(__dirname, "../02_주제100선_에디토리얼캘린더.xlsx"));
  const sheet = wb.Sheets["주제100선"];        // 엑셀 시트 이름
  const rows = XLSX.utils.sheet_to_json(sheet);
  for (const r of rows) {
    await prisma.topic.create({
      data: {
        title: r["제목"],
        categoryId: r["카테고리"],
        keyword: r["핵심키워드"],
        searchVolume: Number(r["월검색량"] || 0),
        cpcKrw: Number(r["CPC(원)"] || 0),
        difficulty: Number(r["난이도"] || 50),
        priority: Number(r["우선순위"] || 50),
        plannedDate: r["계획일"] ? new Date(r["계획일"]) : null,
        notes: r["메모"] || null,
      },
    });
  }
  console.log(`[OK] ${rows.length} topics imported`);
}
main().finally(() => prisma.$disconnect());
```

실행:
```bash
npm install xlsx
node scripts/import-topics.js
```

## 🧠 체크포인트

- Topic 테이블은 **에디토리얼 캘린더의 실체**. 대표가 `priority`만 조정해도 발행 순서가 바뀐다.
- 발행되면 `status=PUBLISHED` + `postId` 연결.
- 매주 금요일 `npm run topic:report`로 주간 발행 예정 리스트를 콘솔에 출력하는 스크립트도 추가 추천.
